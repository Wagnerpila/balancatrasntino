💲 Tabela de valores das pesagens

Por pesagem: valor fixo a cada pesagem. Por tonelada: valor × toneladas de peso líquido. Pacote mensal: mensalidade fixa com um número de pesagens incluídas; as que passarem pagam o valor do excedente.
A tabela marcada como padrão vale para quem não tem tabela própria. Ligue a tabela à empresa (aba Empresas) ou ao motorista que paga por conta própria (aba Motoristas). Na pesagem, se digitar um valor, ele substitui a tabela só naquela pesagem.

🌐 Espelho na internet (VPS)

    
O sistema e o banco continuam neste computador. O espelho mostra o sistema pela internet, com login, e repassa para cá os comandos de quem acessa de fora. Sem internet, a pesagem aqui continua normal.

    

    

      

      

    

  

  

    
💬 Aviso no WhatsApp

    
Quando um caminhão sobe na balança, o sistema espera a leitura da placa e manda uma mensagem pelo WhatsApp Web com o link para acompanhar pela internet.
      Quem envia é o WhatsApp Web aberto no Chrome (perfil Balança Transtino), com a extensão "Balança Transtino — Avisos no WhatsApp" instalada
      (pasta balanca_nova\whatsapp_extensao). Deixe a aba do WhatsApp Web aberta.
